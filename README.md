# Cow-hat

Client-side Forge 1.8.9 mod for Hypixel. Any player wearing a cow hat (a helmet-slot
item with "cow" in its name) has it replaced with a Star of David above their head.

Build: `./gradlew build` (needs a Gradle wrapper / Gradle 2.14 for ForgeGradle 2.1), jar lands in `build/libs/`.
Status: untested; written without access to a Forge build environment.
